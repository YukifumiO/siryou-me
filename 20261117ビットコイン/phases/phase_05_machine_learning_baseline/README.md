# Phase 5：機械学習ベースライン

## 目的

説明しやすい統計・機械学習モデルを用いて、市場レジームと将来BTCリターンの予測可能性を、未来情報の混入なしで評価する。

## 予測対象

- 24時間後リターン
- 72時間後リターン
- 7日後リターン
- 上昇・下落・見送りの3分類
- 将来実現ボラティリティ

## 作業

### 1. ナイーブ・統計ベースライン

- Buy & Hold
- 常に見送り
- 前期と同じ方向
- 移動平均ルール
- 線形回帰
- ロジスティック回帰

### 2. 市場レジーム

#### HMM

市場状態の持続確率、遷移確率、各時点の状態確率を推定する。

#### GMM

連続特徴量の確率的クラスタリングを行い、各ガウス成分への所属確率を求める。GMMはPólya treeを試す前の比較基準とする。

#### Pólya tree

次のいずれかがGMMの外部検証で確認された場合に追加実験する。

- 状態内に強い歪度や厚い裾が残る
- 同じ経済的状態が複数ガウス成分に分裂する
- 裾確率が較正不良となる
- 高ボラティリティ条件付きの大幅安確率が主要な研究対象になる

比較する構成：

1. 単一Pólya treeによる同時分布・裾確率推定
2. 状態別Pólya tree混合モデル
3. HMM + Pólya tree観測分布

初期は2～4変数に制限し、分割位置、木の深さ、事前分布への感度を調べる。

### 3. XGBoost / LightGBM

- 各予測期間を別モデルとする
- 回帰と3分類の両方を比較する
- 予測確率を較正する
- SHAPで特徴量寄与を分析する
- レジーム番号・状態確率を特徴量として追加する場合としない場合を比較する

### 4. ウォークフォワード検証

- 時系列順の学習・検証分割
- 予測期間に応じたgap
- ラベル重複を除くpurging / embargo
- ハイパーパラメータ用の内側検証
- 性能評価用の外側検証
- 開発中に繰り返し見ない最終ホールドアウト

### 5. コスト込みバックテスト

手数料、スプレッド、スリッページ、シグナル遅延を含める。予測期待リターンがコストと安全幅を超える場合だけ売買候補とする。

## 評価

### 予測性能

- MAE、RMSE、Rank IC
- PR-AUC、ROC-AUC、F1、MCC、Balanced Accuracy
- Brier score、確率校正
- Pólya treeとGMMの対数スコア、CRPS、裾確率校正

### 経済性能

- コスト控除後損益
- Sharpe、Sortino、Profit Factor
- 最大ドローダウン
- 売買回数、回転率
- 年別・レジーム別成績
- コスト1倍・1.5倍・2倍の感度
