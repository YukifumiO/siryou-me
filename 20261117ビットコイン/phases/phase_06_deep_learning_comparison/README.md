# Phase 6：ディープラーニング比較

## 目的

時系列ディープラーニングが、Phase 5の線形モデルやXGBoost / LightGBMに対して、未知期間と取引コスト控除後に実質的な追加価値を持つか検証する。

## 比較モデル

1. 小型LSTM
2. GRU
3. Temporal Fusion Transformer（TFT）
4. PatchTST（必要に応じて）
5. iTransformer（必要に応じて）

## 作業

### 1. 公平な比較条件

- 同じデータ期間
- 同じ特徴量群
- 同じ予測期間
- 同じウォークフォワード分割
- 同じ取引コストと約定仮定
- 調整に使う計算予算の上限を記録

### 2. モデル実装

- 入力窓と予測窓を明記する
- 入力正規化は学習フォールド内だけでfitする
- Early Stoppingとドロップアウトを使う
- 最低5つ程度のランダムシードで評価する
- モデル規模、学習時間、推論時間を記録する

### 3. TFTの重点評価

- 24時間、72時間、7日の複数ホライズン
- 分位点予測による不確実性
- 変数選択重み
- 時間方向の重要度
- 予測区間の校正
- レジーム別性能

### 4. 過学習の診断

- 学習と検証の損失差
- シード間のばらつき
- 特定期間だけの性能集中
- 入力特徴量のアブレーション
- ハイパーパラメータ探索回数の影響

## 採用基準

ディープラーニングは、次の条件を満たす場合だけ後続Phaseの候補とする。

- 外側検証で基準モデルを上回る
- コスト控除後の成績が改善する
- 利益が一部の取引に集中していない
- 複数シードで劣化しない
- 運用上の計算コストと保守複雑性を上回る価値がある
- 限界と主な判定根拠を説明できる

## 成果物

- 各モデルの実装と設定
- モデルカード
- 基準モデルとの比較表
- シード別・フォールド別結果
- 分位点予測と校正レポート
- 採用・不採用の判断書

## 完了条件

- [ ] LSTM / GRUとTFTを同一条件で比較している
- [ ] XGBoost / LightGBMとの統計的・経済的比較がある
- [ ] ランダムシード間の不安定性を報告している
- [ ] 計算コストを記録している
- [ ] 採用するモデルと理由が明記されている

## 注意点

- 高度なモデルであることを採用理由にしない。
- 一般的な時系列ベンチマークの成績をBitcoin売買の成績とみなさない。
- 同じ最終ホールドアウトを繰り返し調整に使わない。
