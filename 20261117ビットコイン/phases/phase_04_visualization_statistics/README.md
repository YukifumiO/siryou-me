# Phase 4：可視化・統計分析

## 目的

収集データを同一時間軸で観察できるダッシュボードを作成し、データ品質とBTCに対する各指標の先行関係を統計的に調べる。

## 作業

### 1. 基礎ダッシュボード

表示対象：

- BTC
- DXY
- Gold
- VIX
- DVOL
- 米10年債利回り
- BTC ETF Flow

各チャートで期間、粒度、タイムゾーンを共通化する。

### 2. データ品質表示

- 最終取得時刻
- 更新遅延
- 欠損数
- 異常値数
- ソースとバージョン
- 改定の有無

### 3. 基礎統計

- 分布、分位点、歪度、尖度
- リターンの自己相関
- ボラティリティ・クラスタリング
- 季節性、曜日、時間帯
- 欠損と異常値の発生パターン

### 4. 先行相関

次の時間差で、各指標とBTCの将来リターンを比較する。

- 同時
- 1時間先
- 6時間先
- 24時間先
- 72時間先
- 7日先

Pearson相関だけでなく、Spearman相関、分位点別、市場環境別の結果も確認する。

### 5. 初期仮説の一次検証

- DXY下落 + Gold上昇 + BTC ETF流入
- 米10年債利回り上昇 + DXY下落 + ETF流入
- BTC上昇 + DVOL上昇
- BTC下落 + DVOL急騰 + Exchange Inflow増加（データ追加後）

条件成立後のリターン分布、中央値、裾リスク、サンプル数を報告する。

## 注意点

- 複数の時間差・条件を探索した事実を記録し、偶然の有意性に注意する。
- 公表遅延のあるETF Flowなどは`available_at`基準で結合する。
- 同じサンプルを見ながら仮説を無限に追加しない。
