# Phase 1：データ取得元の調査

## 目的

初期分析に必要な7種類の市場データについて、継続利用できる取得先、API仕様、法的・技術的条件を確定する。

## 対象データ

- BTC価格・OHLCV
- DXY
- 米10年債利回り
- Gold
- VIX
- DVOL
- BTC ETF Flow

## 作業

### 1. 取得先候補の列挙

各データについて第一候補と代替候補を最低1つずつ調査する。取引所、公的機関、指数算出元、データプロバイダを区別する。

### 2. API仕様の整理

| 調査項目 | 記録内容 |
|---|---|
| 提供元・URL | 公式サイト、APIエンドポイント |
| 接続方法 | REST、WebSocket、CSV、その他 |
| 認証 | APIキーの要否、権限範囲 |
| 更新頻度 | ティック、分、時間、日次 |
| レート制限 | 短期・長期上限、HTTPヘッダ |
| 過去期間 | 最古のデータ、1回の取得上限 |
| タイムゾーン | 日付境界、夏時間の取り扱い |
| 公表遅延 | 対象時刻と実際の利用可能時刻 |
| 過去改定 | 速報値・確報値・修正履歴 |
| 料金 | 無料枠、有料プラン、追加課金 |
| 利用条件 | 商用利用、保存、再配布、表示要件 |
| 障害対応 | SLA、ステータス画面、代替取得手段 |

### 3. データの定義確認

- 値の単位と通貨
- 指数の算出方法
- 取引所または市場の対象範囲
- ETF Flowの純流入・総流入の定義
- DVOLの対象満期と算出方法
- 欠損、休日、非取引時間の扱い

### 4. 候補の評価

信頼性、取得遅延、過去期間、コスト、商用利用、障害対応を同じ基準で比較する。安価であることだけで決定しない。

## 成果物

- `data_source_catalog.md`：データ取得先一覧
- `api_comparison.csv`：API候補比較表
- `data_licensing_notes.md`：利用条件と要確認事項
- `data_source_decision.md`：採用理由と代替案
- 調査元URLと確認日の記録

## 完了条件

- [ ] 7種類すべてに第一候補がある
- [ ] 重要データに代替取得先がある
- [ ] API認証、制限、料金、過去期間が明記されている
- [ ] 公表遅延と過去改定の有無が明らかである
- [ ] 社内保存と分析に利用できる見込みがある
- [ ] Phase 2で接続試験するAPIが決定している

## 注意点

- ブログや二次情報だけで判断せず、公式仕様と利用規約を確認する。
- ETF Flowの対象日と公表時刻を混同しない。
- 画面の手動コピーを長期的なデータ基盤にしない。
